POST /import

Operation ID: identity-merge.

Authentication: basic token (ServiceAccount) or basic token (ProjectSecret) or bearer token (OAuthToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | strict | query | enum: 0, 1 | Yes | When set to 1 (recommended), Mixpanel will validate the batch and return errors per event that failed. | | project_id | query | string | No | The Mixpanel project_id, used to authenticate service account credentials (do not provide if using secret auth). |
